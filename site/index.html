Trading Bot

A Python trading bot with a Flask dashboard, a risk-management library (position sizing, stop-losses, portfolio limits) and an options-pricing experiment comparing Black-Scholes with a small neural network. This page runs the same rules in your browser on simulated prices, so you can see what it does without any accounts or keys.

1. Mean-reversion strategy

The bot checks a stock's price on an interval. If the price fell 2% or more since the previous check it buys 1 share; if it rose 2.5% or more it sells the whole position. Below, prices are a random walk (not market data) so you can watch the rule fire.

    2. Position sizing

    Port of src/risk/position_sizer.py. It computes three sizes and takes the smallest: fixed % of the account, volatility-adjusted (risk / 2 x ATR), and half-Kelly (capped at 20%).

    3. Options pricing: Black-Scholes vs neural network

    The repo pulls an AAPL call-option chain with yfinance, prices it with Black-Scholes, trains a small PyTorch network on strike and implied volatility, and flags contracts where the network's price differs from the last traded price by more than $0.50. These are the actual rows saved in the repo (trading_signals.csv, AAPL calls expiring 2025-03-07).

    Caveat: the network was trained on 80% of these same 55 rows and evaluated on all of them, so its low error is mostly in-sample fit, not a forecast. Black-Scholes here uses a fixed stock price of $180 and 30 days to expiry, as hard-coded in black_scholes.py.

    Educational project, not financial advice. The live app uses Alpaca paper trading when you add your own free paper keys; without keys it runs in a simulated demo mode. Built with Pico CSS and Chart.js (both MIT).
